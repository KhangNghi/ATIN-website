# ATIN website

Public site for the **AgeTech Investor Network** — a curated angel syndication platform developed by [AgeTech Capital](https://agetechcapital.com/) in collaboration with The AgeTech Collaborative™ by AARP.

## Stack

- React 19 + TypeScript
- TanStack Start / Router
- Tailwind CSS v4
- Vite + Nitro (Vercel)

## Local

```bash
npm install
npm run dev
```

The app serves at `http://localhost:8080`.

```bash
npm run typecheck
npm run build
```

## Pages

Home, portfolio, company pages, angels, startups, committee, market, apply, events, FAQ, contact.

Member deal rooms and commitments live on the [investment portal](https://agetechcapital.vessel.co/login), not on this site.
